# Agent Radio

Sanitized source baseline derived from the local Agent Radio v11.2 JANG narration canary.

## Scope

This repository is a source-control baseline for reviewable application changes. It does not contain production service controls, model files, credentials, runtime state, telemetry, rehearsal artifacts, or the production station catalog.

## Safety

No automated process may merge, deploy, start, stop, reconfigure, or probe Agent Radio, JANG, Ornith, NeuTTS, or other local services from this repository.
