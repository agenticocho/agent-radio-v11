⚠ Agent Radio needs its local relay

  1. Open the folder containing this app.
  2. Double-click Start Agent Radio.command.
  3. It starts the relay on http://127.0.0.1:4200 and opens the app.

Nothing is uploaded — the relay runs locally on your Mac. A pure serverless single-file version isn't possible because many stations block browser CORS / hotlink protection, and ICY metadata plus favicon fetching require a same-origin localhost relay.
